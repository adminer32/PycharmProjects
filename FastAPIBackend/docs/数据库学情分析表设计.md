# 学生学情分析数据库表设计

## 概述

本数据库用于支持学生学情分析功能，包括学习时长、打卡记录、作业成绩、动作能力评分和毽球技能评估等数据。

---

## 表结构

### 1. student_learning - 学习记录表

| 字段               | 类型          | 说明           |
| ------------------ | ------------- | -------------- |
| id                 | BIGINT        | 主键，自增     |
| student_id         | BIGINT        | 学生ID         |
| learning_hours     | DECIMAL(10,2) | 学习时长(小时) |
| last_learning_time | TIMESTAMP     | 最后学习时间   |
| created_at         | TIMESTAMP     | 创建时间       |

---

### 2. student_checkin - 打卡记录表

| 字段         | 类型                         | 说明         |
| ------------ | ---------------------------- | ------------ |
| id           | BIGINT                       | 主键，自增   |
| student_id   | BIGINT                       | 学生ID       |
| checkin_date | DATE                         | 打卡日期     |
| checkin_type | ENUM('AI_CLASS', 'TRAINING') | 打卡类型     |
| duration     | INT                          | 学习时长(秒) |
| created_at   | TIMESTAMP                    | 创建时间     |

---

### 3. homework_scores - 作业成绩表

| 字段          | 类型         | 说明       |
| ------------- | ------------ | ---------- |
| id            | BIGINT       | 主键，自增 |
| student_id    | BIGINT       | 学生ID     |
| homework_date | DATE         | 作业日期   |
| score         | DECIMAL(5,2) | 作业分数   |
| created_at    | TIMESTAMP    | 创建时间   |

---

### 4. action_scores - 动作能力评分表

| 字段              | 类型         | 说明                                     |
| ----------------- | ------------ | ---------------------------------------- |
| id                | BIGINT       | 主键，自增                               |
| student_id        | BIGINT       | 学生ID                                   |
| action_type       | VARCHAR(50)  | 动作类型(如：盘踢、磕踢、外摆踢、里合踢) |
| current_score     | DECIMAL(5,2) | 当前评分                                 |
| history_avg_score | DECIMAL(5,2) | 历史平均分                               |
| recent_scores     | JSON         | 最近5次练习分数数组                      |
| feedback          | JSON         | AI反馈建议数组                           |
| updated_at        | TIMESTAMP    | 更新时间                                 |

**唯一索引**: `uk_student_action` (student_id, action_type)

---

### 5. shuttlecock_skills - 毽球技能评估表

| 字段            | 类型         | 说明                                             |
| --------------- | ------------ | ------------------------------------------------ |
| id              | BIGINT       | 主键，自增                                       |
| student_id      | BIGINT       | 学生ID                                           |
| skill_type      | VARCHAR(50)  | 技能类型(如：盘踢、绷踢、拐踢、磕踢、踏踢、跳踢) |
| personal_score  | DECIMAL(5,2) | 个人分数                                         |
| class_avg_score | DECIMAL(5,2) | 班级平均分                                       |
| updated_at      | TIMESTAMP    | 更新时间                                         |

**唯一索引**: `uk_student_skill` (student_id, skill_type)

---

## 动作类型枚举

| action_type | 说明         |
| ----------- | ------------ |
| 盘踢        | 基本踢法     |
| 磕踢        | 膝盖踢法     |
| 外摆踢      | 外侧摆动踢法 |
| 里合踢      | 内侧合拢踢法 |
| 绷踢        | 绷脚踢法     |
| 拐踢        | 侧身踢法     |
| 踏踢        | 踏地踢法     |
| 跳踢        | 跳跃踢法     |

---

## 打卡类型枚举

| checkin_type | 说明             |
| ------------ | ---------------- |
| AI_CLASS     | 通过AI课堂打卡   |
| TRAINING     | 通过训练计划打卡 |

---

## 关联说明

- 所有表通过 `student_id` 与 `users` 表关联
- `student_id` 对应 `users.id` 或 `student_profile.student_id`
